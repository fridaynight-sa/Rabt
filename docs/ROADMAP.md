# Roadmap

Each phase ends with a version the owner tries and approves before the next.

| Phase                    | Scope                                                                                                                                                         | Status                     |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------- |
| 1. Foundation            | Project structure, docs, CI, full database schema with RLS and tests, sign up (merchant, provider), login by email or phone, password reset, role-based pages | Done                       |
| 2. Providers             | Provider dashboard: edit page, sectors and categories, portfolio images (R2), public provider page, WhatsApp button                                           | Done, waiting for approval |
| 3. Listings and search   | Create listings with images, card grid, home page, search, filters, category pages                                                                            |                            |
| 4. Merchants and ratings | Reviews with comments, reports                                                                                                                                |                            |
| 5. Admin                 | Stats and visits, manage accounts and content, audit log, admin 2FA                                                                                           |                            |
| 6. Launch                | Security review, performance, SEO and WhatsApp link previews, monitoring, backups, Turnstile, weekly checks                                                   |                            |

Later, when needed: custom domain, verified badge, favourites, Supabase Pro.
